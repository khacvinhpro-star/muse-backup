# POV 20s product-review video template

Goal ID: goal_399d70a2860f
Goal slug: pov-20s-product-review-video-template

## Description
A reusable POV product-review format: 20-second vertical 9:16 videos with review voiceover, keeping each product exactly as photographed while changing the background, preferably to a luxurious store setting. The template covers shoes and now household, fashion and grocery products, with actions required to be physically realistic, so Kevin can send a new product photo and get the same style again.
