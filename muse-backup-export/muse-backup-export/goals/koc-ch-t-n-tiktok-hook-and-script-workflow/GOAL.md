# KOC Chốt Đơn TikTok hook and script workflow

Goal ID: goal_271c3cbc42c1
Goal slug: koc-ch-t-n-tiktok-hook-and-script-workflow

## Description
A reusable TikTok Shop sales-script system for Kevin's products. It researches each product, proposes at least five approaches with hooks for Kevin to choose, then writes a roughly 140-word script in one flowing paragraph after he approves a hook. Scripts use natural Vietnamese addressing viewers as “các bác” and never invent prices, certifications, or unverified benefits.
